# Изображения примерного каталога

Фото — примеры наполнения из Unsplash. Перед реальными продажами загрузите изображения и характеристики вашего ассортимента через админ-панель. Изображения не являются доказательством происхождения или бренда товара.

Главная: [Alireza Esmaeeli — повседневный образ](https://unsplash.com/photos/o-9cVbnO-lk), изображение `photo-1626596662792-12cdc7ecce71`.

Сумка: [Fauzan Fathullah — сумка на светлом фоне](https://unsplash.com/photos/a-leather-bag-on-a-white-surface-SpxXRctFf08), изображение `photo-1657603635372-023411921d31`.

Фото включены в `backend/prisma/seed-assets`. Seed копирует их в каталог uploads без перезаписи существующих файлов. Сайт загружает их со своего API, поэтому показ каталога не зависит от доступности Unsplash. Исходный URL каждого файла: `https://images.unsplash.com/<имя-файла-без-.jpg>`. Список задаётся в `backend/prisma/seed-products.ts`; служебная загрузка — `scripts/download-seed-images.mjs`.

Проверка HTTP-загрузки и визуальная контактная таблица генерируются командой `node scripts/check-images.mjs` при запущенном API. Результаты лежат в `.local/image-review/`.

Использование фотографий регулируется [лицензией Unsplash](https://unsplash.com/license). Права на изображённые бренды и реальный товарный ассортимент остаются отдельным вопросом продавца.
