# FORMA — интернет-магазин одежды

## Исходные требования
Основание: `C:/Users/USER/Downloads/agent.md`, предоставленный пользователем. Пустой репозиторий. Пользователь выбрал магазин одежды; рабочий бренд FORMA, русский интерфейс, валюта KZT. Реальная оплата картой и отправка писем требуют внешнего провайдера: реализуем заказ с оплатой при получении и отдельную сущность Payment без фиктивного списания средств.

## Архитектура и стек
Монорепозиторий npm workspaces: `/frontend` (React, TypeScript, Vite, React Router, TanStack Query, Zustand, React Hook Form, Zod), `/backend` (Express, TypeScript, Prisma, PostgreSQL), `/docs`, `/scripts`. Express выбран ради простого модульного REST API и прозрачных middleware. Сервер — источник истины для цен, остатков, ролей и заказов. Деньги — целые тенге. Клиент не передаёт итоговую цену заказа.

## Этапы и проверки
1. План, контракт API, соглашения, дизайн-система.
2. Prisma schema, миграция, seed, настоящий локальный PostgreSQL.
3. Backend: авторизация, каталог, корзина, избранное, транзакционные заказы, профиль, отзывы, загрузки и администрирование.
4. Frontend: главная, каталог, поиск, карточка, корзина, checkout, профиль, история, админ-панель. Независимая работа агентов по согласованному контракту.
5. Интеграция: build, API тесты на PostgreSQL, исправления.
6. Browser QA: desktop/tablet/mobile, основной путь покупки, админ-панель, ошибки, доступность.
7. Независимый review, документация и Docker; фактические результаты проверок записываются отдельно.

## Сущности
User, Role enum, RefreshToken, Address, Category, Product, ProductImage, ProductVariant, Inventory, Cart, CartItem, Favorite, Order, OrderItem, Review, Payment, ShippingMethod. Уникальные email/slug/SKU, индексы поиска и связей, внешние ключи, временные отметки. Soft delete товаров/пользователей. OrderItem хранит snapshot; остатки обновляются условно и атомарно в транзакции, повтор заказа ограничен idempotency key.

## API
Базовый путь `/api`; точный контракт — `docs/API_CONTRACT.md`. Модули auth, users, products, categories, cart, favorites, orders, reviews, admin, uploads, health. Cookie refresh token + короткий access JWT, проверка актуальной роли в БД, строгая валидация, CORS, rate limiting, безопасные загрузки.

## Roadmap запуска
Установить зависимости; инициализировать PostgreSQL, применить миграции и seed; запустить API и Vite; проверить build и тесты; пройти покупку и администрирование в браузере; подготовить docker-compose и инструкции.
